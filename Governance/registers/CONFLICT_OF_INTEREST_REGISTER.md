# Conflict-of-Interest Register

This register records declared conflicts of interest for contributors and
decision-makers in TeachLink Mobile. Its purpose is to keep decisions fair and
transparent by making interests visible and documenting recusals.

## Declared-Interest Fields

Each declaration records the following fields:

| Field | Description |
|-------|-------------|
| Declaration ID | Sequential identifier (for example, `COI-0001`). |
| Person | Name or GitHub handle of the declaring person. |
| Role | The role the person holds. |
| Interest type | Financial, employment, affiliation, or personal. |
| Description | The nature of the interest. |
| Related matters | Decisions or matters the interest could affect. |
| Recusal required | Yes or No. |
| Declared on | Date the interest was declared. |
| Last reviewed | Date of the most recent review. |
| Status | Active or Cleared. |

## Recusal Record

When a person is recused from a decision, the recusal is recorded with the
matter, the date, and the substitute or remaining decision-makers. Recused people
do not count toward quorum or a vote on that matter. See
[`Governance/policies/QUORUM.md`](../policies/QUORUM.md).

## Review Cadence

- Declarations are reviewed **annually** by the maintainers.
- A declaration is updated whenever a person's interests change.
- Cleared declarations keep their entry and are never deleted.
