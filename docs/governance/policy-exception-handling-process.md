# Policy Exception Handling Process

This document defines how policy exceptions are requested, reviewed, and approved.

## When to Use
When a contributor or team needs to deviate from an established policy.

## Steps
1. Requestor submits a GitHub Issue with the exception-request label
2. Describe the policy, reason for exception, and duration
3. Lead maintainer reviews the request within 5 business days
4. If approved, the exception is documented with an expiry date
5. Exceptions are reviewed at the next governance review

## Denial
Denied exceptions are documented with the reason provided to the requestor.
