# Treasury Reconciliation Runbook

This runbook describes the quarterly treasury reconciliation process.

## Frequency
Quarterly, within 14 days of the end of each quarter.

## Steps
1. Export all transactions from the treasury tool for the quarter
2. Match transactions against approved budgets and disbursements
3. Identify and investigate any discrepancies
4. Prepare a reconciliation report
5. Submit report for review by 2 maintainers
6. Publish the approved report in docs/reports/treasury-YYYY-QN.md

## Escalation
Discrepancies over $100 must be escalated to the project lead immediately.
