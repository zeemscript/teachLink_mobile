# Access Review Runbook

This runbook defines the process for conducting periodic access reviews.

## Frequency
Bi-annual (every 6 months) and after any team member change.

## Steps
1. Export the list of all contributors with repository access
2. Compare against current active contributor list
3. Remove access for inactive or departed contributors
4. Document all changes with justification
5. Notify affected contributors of access changes
6. Publish summary in the governance report

## Escalation
Unauthorized access found during review must be revoked immediately.
