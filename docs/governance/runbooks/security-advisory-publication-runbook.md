# Security Advisory Publication Runbook

This runbook covers the steps for publishing a security advisory.

## Trigger
A confirmed security vulnerability affecting users of TeachLink Mobile.

## Steps
1. Confirm and assess severity using CVSS scoring
2. Develop a fix or mitigation
3. Draft advisory in the GitHub Security Advisories tool
4. Coordinate with reporters for responsible disclosure
5. Publish advisory and release patched version simultaneously
6. Announce in community channels

## Embargo Period
A 90-day embargo is the default unless the vulnerability is being actively exploited.
