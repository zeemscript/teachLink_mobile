# Maintainer Election Runbook

This runbook describes how new maintainers are elected.

## Eligibility
- Minimum 3 months of active contribution
- At least 5 merged pull requests
- Nomination by an existing maintainer

## Process
1. Nomination is posted in GitHub Discussions
2. Community feedback period: 7 days
3. Current maintainers vote (simple majority required)
4. Result is announced and new maintainer is onboarded

## Onboarding
- Grant repository write access
- Add to MAINTAINERS.md
- Invite to maintainer communication channels
