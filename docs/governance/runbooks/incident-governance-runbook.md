# Incident Governance Runbook

This runbook defines how governance incidents are handled.

## Definition
A governance incident is any violation of project policies or a breakdown in governance processes.

## Steps
1. Identify and document the incident
2. Notify lead maintainer within 1 hour
3. Assess severity (low / medium / high)
4. Assign an incident owner
5. Resolve the incident and document the resolution
6. Conduct a post-incident review within 7 days

## Documentation
All incidents are logged in docs/incidents/.
