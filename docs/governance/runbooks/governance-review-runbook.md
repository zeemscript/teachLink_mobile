# Governance Review Runbook

This runbook defines the steps for conducting a governance review.

## Frequency
Annually, in Q4, or when triggered by a major incident.

## Steps
1. Collect all current governance documents
2. Review each document for accuracy and relevance
3. Identify gaps or outdated content
4. Propose updates via pull requests
5. Obtain approval from at least 2 maintainers per change
6. Publish updated documents and summarize changes

## Output
A governance review report is published in docs/reports/governance-review-YYYY.md.
