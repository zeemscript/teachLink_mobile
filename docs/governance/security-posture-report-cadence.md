# Security Posture Report Cadence

This document defines the cadence for publishing security posture reports.

## Frequency
- Quarterly security posture summaries
- Immediate reports after any security incident

## Contents
- Summary of vulnerabilities identified and resolved
- Outstanding security issues
- Dependency audit results
- Access review results

## Ownership
The security lead is responsible for authoring and publishing these reports.

## Distribution
Published in docs/reports/security-posture-YYYY-QN.md.
