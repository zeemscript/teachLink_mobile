# Branch Protection Policy

This document defines the branch protection rules for TeachLink Mobile.

## Protected Branches
- main: production-ready code
- develop: integration branch

## Rules
- Require pull request reviews before merging (minimum 1 approval)
- Require status checks to pass before merging
- Require branches to be up to date before merging
- Restrict who can push to protected branches
- Do not allow force pushes
- Do not allow branch deletions

## Enforcement
All contributors must follow these rules. Violations should be reported to the maintainers.
