# Metrics Dashboard Governance Policy

This policy defines how the TeachLink Mobile metrics dashboard is governed.

## Purpose
Ensure metrics are accurate, accessible, and actionable for maintainers and contributors.

## Metrics Tracked
- Active contributors per month
- Issue resolution time
- PR merge rate
- Test coverage percentage

## Access
- Metrics dashboard is publicly readable
- Only maintainers may update metric definitions

## Review Cadence
Metrics are reviewed monthly by the core team.
