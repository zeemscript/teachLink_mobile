# GDPR Compliance Overview

This document outlines GDPR compliance requirements for TeachLink Mobile.

## Key Principles
- Data minimization: collect only what is necessary
- Purpose limitation: use data only for stated purposes
- Storage limitation: retain data no longer than needed
- Integrity and confidentiality: protect data from unauthorized access

## User Rights
- Right to access personal data
- Right to rectification
- Right to erasure (right to be forgotten)
- Right to data portability

## Compliance Actions
- Maintain a data processing register
- Conduct Data Protection Impact Assessments (DPIA) for high-risk processing
- Appoint a Data Protection Officer (DPO) if required
