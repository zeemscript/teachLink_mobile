# Governance Document Review Process

This document defines the process for reviewing and updating governance documents.

## Triggers
- Scheduled annual review
- Policy violation incident
- New regulatory requirement

## Steps
1. Identify the document(s) needing review
2. Assign a reviewer (must be a maintainer)
3. Reviewer proposes changes via a pull request
4. Minimum 2 maintainer approvals required to merge
5. Updated document is published and announced

## Record Keeping
All review history is preserved in git history.
