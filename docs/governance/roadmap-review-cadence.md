# Roadmap Review Cadence

This document defines how and when the project roadmap is reviewed.

## Frequency
- Quarterly roadmap reviews
- Ad-hoc reviews triggered by major releases or incidents

## Process
1. Maintainers draft roadmap updates
2. Changes are proposed via a GitHub Discussion
3. Community feedback period: 2 weeks
4. Final roadmap published and pinned

## Ownership
The project lead maintainer owns the roadmap document.

## Location
Roadmap is maintained at docs/ROADMAP.md.
