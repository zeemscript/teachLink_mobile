# OKR and Goal Governance Policy

This policy establishes how Objectives and Key Results (OKRs) are set and tracked.

## Cadence
- OKRs are defined at the start of each quarter
- Progress is reviewed monthly
- Final review at end of quarter

## Process
1. Maintainers propose objectives in a GitHub Discussion
2. Community provides feedback for one week
3. Final OKRs are published in docs/goals/

## Accountability
Each objective must have a named owner from the maintainer team.
